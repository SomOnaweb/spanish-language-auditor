# Spanish (Spain) Language Auditor

Skill for ensuring correct, natural, and consistent Spanish (Spain) across written content.

### Features
- Applies Spanish orthographic and grammatical conventions.
- Corrects spelling, punctuation, and syntax.
- Ensures proper capitalization.
- Detects literal translations and unnecessary anglicisms.
- Improves linguistic consistency and naturalness.
- Follows RAE, ASALE, and FundéuRAE recommendations.

### Installation

Place `SKILL.md` in:

```text
.agents/skills/spanish-language-auditor/SKILL.md
```

### Core principle

**Write in natural, correct Spanish, following the linguistic conventions of Spain rather than translating or imitating other languages.**
